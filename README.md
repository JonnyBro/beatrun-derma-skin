# Beatrun Derma Skin

A Derma skin made to look like the [Beatrun's](https://github.com/JonnyBro/beatrun) style: flat panels, blurred windows and red accents.

You don't need to have Beatrun installed, but if you have Beatrun it will follow it's selected

## Usage

- **ULX** - open the menu (`!menu`), go to Settings → Client and pick **Beatrun** as the skin.
- **Everything** - set `Beatrun_GlobalDermaSkin 1` in the console to use the skin for every Derma window: Spawn menu, context menu and other addons. In Beatrun there's a checkbox for it in the settings.

> [!NOTE]
> Some addons have dark text hardcoded for the default light skin, it can be hard to read with the global option.

Other addons can use it too with `panel:SetSkin("Beatrun")`.

## Installation

### Steam Workshop

1. Subscribe to the addon.

### Manual Installation

1. Download the repository.
1. Extract it into `your_game_folder/garrysmod/addons`.
